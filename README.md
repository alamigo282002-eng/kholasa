## 📖 حول المنصة (About Khulasa)

**خُـلاصة** منصة عربية فاخرة تقدم زبدة أمهات الكتب العالمية في تطوير الذات، المال والأعمال، الإنتاجية، وعلم النفس ملخصة في **5 صفحات تطبيقية مركزة**، مع **قارئ صوتي ذكي** وتصميم **Zen** مفتوح يريح العين والعقل، لتحويل القراءة إلى نتائج يومية ملموسة في 5 دقائق فقط.

---

## ✨ أبرز مميزات صفحة وتطبيق خُـلاصة

1. **🌿 تصميم Zen المفتوح:** شاشة تنفسية مريحة تركز على الفكرة والجوهر بدون صناديق خانقة أو تشتيت.
2. **💡 سؤال اليوم المتغير:** أسئلة فلسفية وعملية تنبع من معضلة الكتاب وتخاطب واقع القارئ مباشرة.
3. **🎧 قارئ صوتي متطور (5 سرعات):** تحكم في سرعة الصوت (0.75x - 2.0x)، نبرة الصوت، وأزرار تخطي 10 ثوانٍ.
4. **📑 هيكل الـ 5 صفحات المعتمد:**
   - **الصفحة 1:** الفكرة الجوهرية وسؤال الصدمة المعرفية.
   - **الصفحة 2:** القواعد الأربع الحاكمة المستخلصة من الكتاب.
   - **الصفحة 3:** التوجيهات العملية والتحذيرات من الفخاخ.
   - **الصفحة 4:** درر الاقتباسات الجاهزة للمشاركة.
   - **الصفحة 5:** خطة الـ 24 ساعة والتطبيق الفوري.
5. **📸 صانع بطاقات الاقتباسات:** حوّل أي اقتباس ملهم إلى بطاقة راقية لمشاركتها على السوشيال ميديا.
6. **🔥 تحدي الستريك اليومي:** تشجيع بلهجة عامية مصرية محفزة تحتفل بإنجازك اليومي.

## 🚀 تشغيل صفحة الهبوط محلياً

افتح ملف `index.html` في أي متصفح، أو شغل خادماً محلياً:

```bash
# باستخدام بايثون
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```
